# Wyrd Qt6 desktop application

Run the GUI:

~~~bash
bash qt-ui/run.sh
~~~

Install the regular desktop menu entry:

~~~bash
bash qt-ui/install-desktop-launcher.sh
~~~

Wyrd detects Skyrim SE and compatible Steam Proton builds, installs official MO2 into a user-local Wyrd-owned location, initializes a dedicated MO2 Proton prefix, and launches MO2 through that Proton runtime. The Qt application itself remains a native Linux application.

## Experimental Steam shortcut bootstrap

Wyrd can install an optional native desktop launcher intended to be added
manually to Steam as a non-Steam game.

1. In Wyrd, choose **Install Steam launcher**.
2. In Steam, choose **Games → Add a Non-Steam Game** and select
   **Wyrd - Skyrim through MO2**.
3. In the shortcut's Properties, leave **Force the use of a specific Steam Play
   compatibility tool** disabled. Wyrd is a native Linux Qt application.
4. Launch that shortcut. Steam starts Wyrd's native bootstrap, which records
   an allow-listed environment snapshot and opens Wyrd with the configured
   MO2 instance.

The generated desktop entry invokes the standard-library-only
`steam_bootstrap.py` using the Python interpreter that installed Wyrd. The
bootstrap writes the allow-listed snapshot, then delegates to `qt-ui/run.sh`
so Qt starts from the same project virtual environment and PySide6 installation
as the regular launcher. Wyrd does not try to run Python or Qt inside Proton.

**Important limitation:** this is a Steam-managed *native bootstrap*, not yet a
Steam-managed Proton launch of MO2 or Skyrim. Wyrd still invokes the selected
Proton build for MO2 itself. A non-Steam shortcut ID being inherited by the
child process does not prove that the full Steam Runtime environment or audio
path is reproduced. Audio improvement is not assumed or claimed.

The Steam shortcut identity is generated by Steam; Wyrd does not guess or
hard-code it. The current integration intentionally does not edit
`userdata/<account>/config/shortcuts.vdf`, Steam compatibility mappings,
Skyrim's real AppID manifest, launch options, game files, saves, or either
Proton prefix.

## Remove the experimental launcher

Use **Remove Steam launcher** in Wyrd. It removes only the Wyrd-owned desktop
entry and its ownership marker, and only if their ownership/hash checks pass.
It does not remove the shortcut already imported into Steam; remove that
entry manually in Steam. It never changes other Steam shortcuts.

## Comparing Steam and Wyrd environments

When launched through the Steam-added shortcut, Wyrd records an allow-listed
environment snapshot at:

`$XDG_DATA_HOME/wyrd/logs/steam-bootstrap-environment.json`
(normally `~/.local/share/wyrd/logs/steam-bootstrap-environment.json`).

The snapshot includes Steam identity, selected Steam Runtime/library paths,
PulseAudio/PipeWire socket variables, and display-session variables. It does
not serialize the complete environment or secrets. Compare these values with
the corresponding environment of a known-good Steam-launched Proton game;
do not infer audio correctness from shortcut identity alone.

## Safety boundaries

- Existing MO2 installations outside Wyrd's managed path are left untouched.
- The Skyrim game prefix and Steam installation are not reset or replaced.
- Game Mode symlinks are created only after review and explicit confirmation.
- Steam shortcut installation is opt-in and reversible.
- The native desktop launcher remains available as a fallback.
